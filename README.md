# Оптимизация производственного расписания

Проект ВКР для мебельного производства. Система строит расписание заказов с учётом доступности сотрудников и станков. Для расчёта используется OR-Tools CP-SAT. Результаты можно просмотреть в Streamlit и выгрузить в Excel.

## Запуск

Из корня проекта выполните:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

В комплекте есть синтетические данные: `data_out/synthetic_medium_150_new.xlsx`. Интерфейс выбирает этот файл по умолчанию.

Для запуска из терминала используйте `python run.py`. Список параметров доступен через `python run.py --help`.
